# Agents

## Cursor Cloud specific instructions

This repository is a **documentation-only showcase** for the Fenrir Telegram Lock product. It contains no application source code, no dependencies, no tests, and no build artifacts.

### What's here

- `README.md` — product description and positioning
- `ROADMAP.md` — feature roadmap (MVP / Next / Later)
- `SECURITY.md` — security policy
- `LICENSE` — all-rights-reserved license
- `.gitignore` — hints at a Node.js stack used in the private repo

### What's NOT here

The actual application source code, backend logic, Telegram bot implementation, database schemas, deployment configuration, and credentials all live in a separate private repository. There is nothing to install, build, lint, test, or run in this repo.

### Development notes

- No `package.json`, lockfile, or dependency manifest exists — `npm install` / `pnpm install` are not applicable.
- No dev server, build command, or test suite exists.
- Contributions to this repo are limited to documentation, roadmap, and public-facing product information.
