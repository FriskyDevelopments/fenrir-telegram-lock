### What this repo contains

- `README.md` — Product description, pricing, and example flow
- `ROADMAP.md` — MVP and future feature roadmap
- `SECURITY.md` — Security disclosure policy
- `LICENSE` — All rights reserved (Frisky Developments, 2026)
- `.gitignore` — Standard ignores (hints at a Node.js stack in the private repo)

### What this repo does NOT contain

The actual application (backend, Telegram bot, DNS automation, admin UI, etc.) lives in a **separate private repository**. There is nothing to install, build, lint, test, or run here.

### Development environment

No setup is required. There are no dependencies to install and no services to start. Future agents should not attempt to run build, lint, or test commands — they will find no targets.

If the private application code is ever merged into this repo, this section should be updated with proper setup instructions.
