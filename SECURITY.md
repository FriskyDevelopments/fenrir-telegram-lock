# Security Policy

Fenrir Telegram Lock handles access-control workflows for Telegram groups.

This public repository is a showcase only. Do not disclose private Telegram invite links, bot tokens, DNS credentials, Cloudflare API tokens, customer domains under active setup, or billing data in public issues.

## Reporting Sensitive Issues

If you find a security concern, contact Frisky Developments privately instead of opening a public issue.

## Scope

Public repo scope:

- Product positioning
- Public roadmap
- Non-sensitive setup concepts
- Feature requests

Private scope:

- Application source code
- Telegram bot implementation
- API tokens and secrets
- Customer records
- Production infrastructure
- Billing configuration
